# CLI

The `suspkin` command line is built with Typer. Command groups live in `suspkin.cli.vehicle`,
`suspkin.cli.study`, `suspkin.cli.surrogate` and `suspkin.cli.webapp`. Every command, option and
example is described in the [CLI guide](../guides/cli.md); run `suspkin --help` for the live list.
